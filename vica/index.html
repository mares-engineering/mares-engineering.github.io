VICA

Visor de Carrera

A VR-native race-awareness instrument built to present a small number of useful cues while keeping the forward view clear.

Read the manual Trust and safety

Product thesis

Only the cue that supports the decision.

VICA is not a dashboard. Each display element has a defined purpose, visibility rule, and stale-data behavior. If the underlying state is missing, stale, or uncertain, the cue hides.

Display elements

Current private-alpha instruments.

Wind

Direction relative to the car; segment length represents magnitude.

Incidents

A compact xN session incident readout.

Minimum corner speed

A latched minimum from the latest meaningful slowing event, intended for practice and qualifying.

Relative

Experimental nearby-car context on a ±2-second vertical scale. Position-sensitive stale data hides.

Driver control

Control stays with the driver.

OpenXR cues are opt-in. Validate changes in a controlled session, know the disable path before driving, and disable VICA if visibility, attention, or performance is affected.

  • Missing or stale state hides the affected cue.
  • The in-race display does not require a cloud account.
  • VICA is not race control and is not presented as officially approved for competition.
  • This site offers no public installer, account, payment, or licensing flow.

Status

Private alpha.

VICA is being validated through controlled, opt-in testing. The manual and trust page document the current public safety posture without implying broad simulator support or race approval.
