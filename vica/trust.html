Trust, privacy, install safety

Explicit scope. Explicit control.

VICA is a private-alpha OpenXR display tool. Trust begins with narrow claims, visible limits, and a disable path the driver understands before use.

Install posture

No public installer, account, or checkout.

Alpha packages and instructions are controlled so each tester knows what is being run. This website does not collect registrations or provide a production download, account, payment, or licensing flow.

User control

Disable comes before diagnosis.

If a cue affects vision, attention, comfort, or performance, leave the driving session and disable VICA before investigating further.

  • OpenXR display elements are opt-in during private-alpha validation.
  • The supplied disable path should remain available at all times.
  • Changes should be tested in solo or otherwise controlled sessions first.
  • If VICA cannot present a cue reliably, it hides the cue without blocking the simulator.

Data boundaries

The in-race display is local-first.

The current in-race display does not require a cloud account. The OpenXR layer writes a bounded local diagnostic log while active. Recordings and preview files are produced only when a tester runs the corresponding tools.

  • This site does not receive simulator telemetry.
  • Do not share private session traces beyond the agreed alpha support path.
  • Local artifacts may contain session context; review them before sharing.
  • No zero-retention or comprehensive privacy guarantee is claimed.

Product boundaries

A driver aid, not an authority.

VICA provides limited informational cues. It does not replace simulator flags, spotters, race control, driver judgment, or the responsibility to operate safely.

  • No official-race approval, certification, or sanction is claimed.
  • No broad simulator, headset, or runtime compatibility is claimed.
  • No guarantee of safety outcomes or absence of performance impact is made.
  • Private-alpha evidence does not make the product production-ready.
